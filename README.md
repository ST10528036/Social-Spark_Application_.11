"Social Sparks" App
The Social Sparks app is a ifestyle app that gets rid of the mental weight of staying social.
It provides fast and actionable suggestions to help users reach out to friends and family without having to think hard about what to say or when to do thing.

Main functions:
The app asks the user for the current time of day and uses conditional logic to provide a relevant "spark".
When a user types in the time of day, clicks a button and immediately receives a social prompt.
The app uses modern developer tools to ensure that the app and its code within the app is always stable and ready to use.

How it works:
The design was made to form a simple text field where the user enters the period of the day.
The app looks at the word entered and matches it to a specific category of social interaction.
The app the updates the screen with a specific "Social Spark" fitted to that moment.
I integrated GitHub to manage my code versions, ensuring every update is tracked and automatically tested.
